# Libro Hespérides — edición gratuita

Aplicación web instalable para mantener un libro personal de operaciones con
criptoactivos y conservar su archivo justificativo.

## Principios

- Gratuita y sin registro.
- Los datos permanecen en el navegador.
- Funciona sin conexión una vez instalada.
- Permite descargar y restaurar una copia completa en JSON.
- No incluye contenidos, ejercicios ni herramientas docentes.

## Desarrollo

```bash
npm ci
npm run dev
```

Comprobaciones antes de publicar:

```bash
npm run typecheck
npm run test
npm run build
```

## Aviso

La aplicación ayuda a organizar información y documentación. No presta
asesoramiento jurídico, contable o fiscal.
